# Tea Shop – Software Engineering Project

## Project Overview

Tea Shop is an academic software engineering project developed as part of the **COMP433 – Software Engineering** course at Birzeit University.

The project focuses on the **requirements analysis, system modeling, and architectural design** of an online tea shopping platform that serves individual customers and businesses (B2B).

The project covers the analysis and design phases of the Software Development Life Cycle (SDLC). **No functional application was implemented.**

## Project Objectives

- Identify and document user and system requirements.
- Analyze system actors and user interactions.
- Model system behavior using UML diagrams.
- Design a modular and maintainable software architecture.
- Apply software engineering principles to support reliability, scalability, and extensibility.

## Proposed System Features

The proposed Tea Shop platform includes:

- User registration and account management
- Product browsing, searching, and filtering
- Personalized tea recommendations
- Custom tea blend creation
- Shopping cart and order checkout
- Online payment processing
- Order tracking and delivery management
- Customer reviews and ratings
- Inventory and product catalog management
- Business-to-business (B2B) ordering

*These features were specified and modeled, not implemented.*

## Requirements Analysis

The project includes:

- Business requirements and system scope
- User and system requirements
- Functional requirements and validation rules
- Actor identification and analysis
- Use case specifications
- Effort and time estimation

Requirements were reviewed and refined throughout the project to maintain consistency between the proposed functionality and system design.

## UML Modeling and System Design

The following diagrams were developed:

- **Use Case Diagram:** Identifies system actors and their interactions.
- **Activity Diagram:** Models the overall system workflow.
- **Class Diagrams:** Represent system entities, attributes, and relationships.
- **Sequence Diagrams:** Illustrate interactions between system components during specific operations.
- **Component Diagram:** Defines the system's major components.
- **Architecture Diagram:** Presents the proposed three-tier layered architecture.
- **Deployment Diagram:** Illustrates the proposed deployment structure.

The design emphasizes low coupling, high cohesion, modularity, extensibility, and transactional data integrity.
